# Tifosi - Base de données

Projet de création d'une base de données MySQL pour le restaurant "tifosi" 

## Contenu du dépot
Fichier : 
- 01_creation_schema.sql : création de la base 'tifosi', de l'utilisateur 'tifosi'
et des tables

- 02_insertion_donnees.sql : insertion des données de test fournies dans le devoir

- 03_requetes.sql : les 10 requetes de verification de la base de données

## Utilisation

Lancer les scripts dans l'ordre 01, 02 puis 03 avec le compte root dans MySQL Workbench
